Inventory App

Deskripsi

Inventory App adalah aplikasi untuk membantu pengelolaan dan pencatatan data barang agar lebih terorganisir dan mudah dipantau.

Fitur

- Menampilkan data barang.
- Menambahkan data barang.
- Mengelola data inventory sesuai fitur yang tersedia pada aplikasi.

Teknologi

- PHP
- MySQL
- XAMPP
- Visual Studio Code

Persyaratan

- XAMPP
- Web browser
- Database MySQL

Cara Menjalankan

1. Simpan folder "inventory-app" di direktori "htdocs".
2. Jalankan Apache dan MySQL melalui XAMPP Control Panel.
3. Siapkan database sesuai konfigurasi aplikasi.
4. Buka browser.
5. Akses "http://localhost/inventory-app".

Database

Aplikasi menggunakan MySQL sebagai database. Konfigurasi koneksi database harus disesuaikan dengan pengaturan lokal.
